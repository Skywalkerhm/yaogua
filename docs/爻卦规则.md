# 爻卦规则

本工具采用传统三枚铜钱起卦法，规则整理自朱熹、蔡元定《易学启蒙》卷下「考变占」。

## 起卦

1. 平心静气，把要问的事情想清楚。
2. 每次掷三枚铜钱，共掷六次。
3. 有字一面为「字」，计 2（阴）；无字一面为「背」，计 3（阳）。
4. 三次之和对应一种爻：

| 和 | 爻 | 阴阳 | 是否动爻 |
| --- | --- | --- | --- |
| 6 | 老阴 | 阴 | 动 |
| 7 | 少阳 | 阳 | 静 |
| 8 | 少阴 | 阴 | 静 |
| 9 | 老阳 | 阳 | 动 |

六爻从下往上排列，形成本卦。老阴（6）动而变阳，老阳（9）动而变阴，变化后的六爻称为变卦（之卦）。

## 断卦

动爻数量不同，取用的卦爻辞也不同：

| 动爻数 | 断法 |
| --- | --- |
| 0 | 占本卦卦辞（彖辞） |
| 1 | 以本卦该动爻的爻辞为主 |
| 2 | 以本卦两个动爻的爻辞为主，上爻为主 |
| 3 | 本卦、变卦卦辞合参，以本卦为主 |
| 4 | 以变卦两个静爻的爻辞为主，下爻为主 |
| 5 | 以变卦唯一静爻的爻辞为主 |
| 6 | 乾用「用九」，坤用「用六」，其余以变卦卦辞为主 |
