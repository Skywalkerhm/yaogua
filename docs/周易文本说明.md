# 周易文本与数据说明

## 原文

数据中的「卦辞」「彖传」「爻辞」为《周易》经传原文（繁体），属于古代经典文本。

- 卦辞：每卦总断，起卦后主要取用的文本。
- 彖传：解说卦辞的传文，作为上下文附在结果中。
- 爻辞：六爻各自的断语，由下往上依次为初、二、三、四、五、上。

## 来源与整理

文本数据整理自开源项目 [ichingshifa](https://github.com/kentang2017/ichingshifa)
（MIT License）中的 `data.pkl`。该项目将《周易》经传整理为机器可读数据。

本工具通过 `tools/build_data.py` 重新整理为：

- `data/hexagrams.js`：网页直接加载的本地数据。
- `data/hexagrams.json`：同一份数据的 JSON 版本，便于检查和使用。

## 解读

每卦的「卦意解读」是本应用原创的简短现代汉语概括，用于帮助阅读卦辞，不是对《周易》
原文的逐字训诂。周易文本意蕴丰富，同一卦在不同情境下可有不同侧重，请结合自身所问之事理解。

从 2026-07 版本起，每卦还带有三栏白话解读（2026-08 起改为更直白的说法）：

- 现在判断：参考传统六十四卦金钱课的卦级，用「上上卦」「中中卦」「下下卦」等给出整体判断。
- 接下来会怎样：用现代汉语转述卦辞指向的处境与走向。
- 现在就做：把卦意落到可执行的做法上。

这三栏内容综合参考华易网六十四卦白话详解、易安居吉祥网周易64卦详解等公开资料编写，
用于帮助理解原文，不构成任何人生决策建议。

从 2026-08 版本起，六十四卦的 384 条爻辞也补上了白话直译，保存在
`data/line_plain.json`。当断卦取用某一爻时，结果页的「白话理解」优先显示该爻直译；
六爻明细表中也会逐爻展示「白话」。

结果页的阅读顺序从 2026-08 版本起调整为：

1. 一句话指引：先告诉你本次占问最需要记住的行动。
2. 白话理解：用现代汉语说清这段卦辞指向的处境。
3. 原文与断卦依据：再展示卦爻辞原文，供对照。
4. 现在判断 / 接下来会怎样 / 现在就做：把结论拆成三栏。

## 按占问方向解读

从 2026-07 版本起，起卦前可以选择占问方向：

- 求事：侧重事业、办事、项目与职场进展。
- 求人：侧重人脉、贵人、合作与求助。
- 求财：侧重财运、经商、投资与收益。
- 求姻缘：侧重感情、婚恋与关系经营。
- 学业：侧重学习、考试、升学与进修。
- 出行：侧重旅行、出差、迁移与行程安排。
- 合作：侧重合伙、签约、项目协作与团队关系。
- 决策：侧重选择、取舍、重大决定与方向判断。

同一卦在不同方向下会显示不同的吉凶判断、卦辞预示与行为建议。方向只改变解读侧重，
不改变卦象和断卦规则。

## 卦变趋势

结果页会根据本卦到变卦的变化额外给出「卦变趋势」，作为辅助参考：

- 把本卦、变卦在当前占问方向下的吉凶等级映射为分数，比较两者的强弱变化。
- 分数上升显示「由弱转强」，下降显示「由强转弱」，持平显示「平势守成」。
- 同时列出动爻位置与阴阳变化，帮助理解卦象从本卦到变卦经历了什么。

卦变趋势不替代朱熹《易学启蒙》断卦规则，只用于说明本卦与变卦之间的关系。

如果六爻皆静，则不产生变卦。结果页会显示「六爻皆静 · 无变卦」，
卦变趋势栏改为说明以本卦卦辞为主，仍按所选占问方向给出解读。
