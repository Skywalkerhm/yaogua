# 爻卦 · 周易六爻小工具

一个可以直接挂在 GitHub Pages 上的静态网页：先静心呼吸，再分六次掷三枚铜钱成卦，最后按《易学启蒙》断卦规则给出本卦、变卦、卦爻辞和原创简短解读。

全部数据都在本地，不调用任何语言模型，也不需要联网。

## 功能

- 静心引导：呼吸圆环，帮助进入稳定状态。
- 六次摇卦：每次掷三枚铜钱，由下往上生成六爻。
- 四象区分：老阴、少阳、少阴、老阳；老阴、老阳自动标记为动爻。
- 本卦与变卦：展示卦象、上下卦、卦序与六爻明细。
- 断卦反馈：按动爻数量取卦辞或爻辞，附彖传、整体卦义，以及每卦的现在判断、未来走向和行动建议。
- 直观指引：结果页先给「一句话指引」和「白话理解」，再把原文放在下方，按「现在判断 / 接下来会怎样 / 现在就做」三栏展开。
- 爻辞白话：384 条爻辞均带现代汉语直译，动爻取爻辞时优先显示该爻白话，六爻明细也会逐爻展示。
- 占问方向：起卦前可选择求事、求人、求财、求姻缘、学业、出行、合作或决策，同一卦按方向切换不同解读。
- 未来走向：根据本卦到变卦的吉凶等级与卦义变化，给出由弱转强、由强转弱或平势守成的趋势判断。
- 六爻皆静：无动爻时不产生变卦，结果页显示「六爻皆静」，断卦以本卦卦辞为主。

## 直接使用

打开 `index.html` 即可，无需构建工具。也可以把整个仓库推到 GitHub 并开启 Pages：

1. 新建仓库并上传本目录内容。
2. 在仓库 `Settings → Pages` 中把 `Source` 设为 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`。
3. 保存后访问 `https://<用户名>.github.io/<仓库名>/`。

## 规则摘要

铜钱法：字为 2（阴），背为 3（阳）。三枚和为 6 老阴、7 少阳、8 少阴、9 老阳；六次由下往上成卦。老阴、老阳为动爻，动则变卦。

断卦（朱熹、蔡元定《易学启蒙》）：

| 动爻 | 取用 |
| --- | --- |
| 0 | 本卦卦辞 |
| 1 | 本卦该爻爻辞 |
| 2 | 本卦两动爻，上爻为主 |
| 3 | 本卦、变卦卦辞 |
| 4 | 变卦两静爻，下爻为主 |
| 5 | 变卦唯一静爻 |
| 6 | 乾坤用九/用六，其余变卦卦辞 |

## 罗盘 · 九宫飞星解读工具

仓库内另有一个独立的静态子工具 `fengshui/`（访问 `https://<用户名>.github.io/<仓库名>/fengshui/`），用于：

- **罗盘 · 二十四山**：输入罗盘读数度数，自动换算坐山向山、卦宫、五行、三元龙，附可点击的二十四山罗盘图；读数落在两山分界线附近会提示「兼线/骑缝」。
- **九宫飞星（玄空下卦）**：选择坐山与元运，自动排出运盘、山盘、向盘（宅命盘），判定旺山旺向、双星到坐/向、上山下水、伏吟、反吟等总断，逐宫解读山向组合，并可叠加流年飞星看当年财位、文昌、五黄等吉凶方位。

排盘方法：运星入中顺飞；山星、向星以坐向所在宫运星入中，按该星在元旦盘所管三山中、与坐向同三元龙之山的阴阳定顺逆（阳顺阴逆）。核心排盘逻辑在 `fengshui/core.js`，可脱离页面用 `node` 直接测试。

同样全部本地运行，不调用任何语言模型。内容为传统术数知识整理，仅供学习参考，不构成任何现实决策建议。

## 数据来源

周易经传原文为公有领域文本，数据整理自 [ichingshifa](https://github.com/kentang2017/ichingshifa)（MIT License）。详细说明见 [docs/周易文本说明.md](docs/周易文本说明.md)。

每卦的「现在判断」「接下来会怎样」「现在就做」为白话解读，综合参考华易网六十四卦白话详解、易安居周易64卦详解等公开资料编写，帮助理解原文。
384 条爻辞白话直译同样参考华易网六十四卦详解整理，动爻取爻辞时优先显示。
